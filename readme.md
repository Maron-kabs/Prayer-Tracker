# ✝️ GraceWalk | Premium Devotional & Prayer Tracker

GraceWalk is a modern, responsive Single Page Application (SPA) designed to help users track and maintain their daily Christian spiritual disciplines. Inspired by gamified habit-builders like Duolingo, it encourages consistency through an interactive streak counter and a visual activity grid.

## ✨ Features

* **Daily Disciplines Checklist:** Tracks four core spiritual disciplines (Morning Devotional, Midday Gratitude, Intercessory Prayer, and Night Reflection).
* **Interactive Progress Ring:** Recalculates completion percentages in real-time with smooth dynamic animations.
* **Smart Streak System:** Automatically calculates consecutive daily completions and tracks your "Best Streak" using browser memory.
* **Spiritual Journal & Archives:** Includes a fully functional logging system with dedicated filters for Scripture Study, Prayer Requests, and Praise Reports.
* **Faith Analytics Grid:** A visual contribution map (similar to GitHub's contribution graph) highlighting your consistency over a 60-day window.
* **Scripture Rotation:** Dynamically displays a unique encouraging verse on the dashboard upon every refresh.

---

## 🛠️ Tech Stack

* **Frontend Structure:** HTML5
* **Styling & Theme:** CSS3 (featuring a premium Deep Midnight Navy and Matte Gold palette with fully responsive fluid layouts)
* **Application Logic:** Vanilla JavaScript (ES6+)
* **Data Persistence:** Browser `localStorage` (your logs and streaks stay completely private and save automatically without needing a database server)
* **Iconography:** FontAwesome v6
